omniAI Demo Day 本地便携包

先解压整个 omniai-demo 文件夹，再运行启动文件。不要在压缩包内双击。
Windows 10/11 x64：双击 START-WINDOWS.cmd。
Mac（Apple Silicon / Intel）：终端进入文件夹，运行 sh START-MAC.command。
Linux（x64 / ARM64，glibc 2.28+）：运行 sh START-LINUX.sh。
已带 Node 22.20.0，不需要 npm install、Docker、VPN，也不需要现场下载。
Windows ARM 电脑需支持 x64 模拟。32 位系统、Chromebook、手机不在支持范围。
本次实机验收为 Windows x64；Mac/Linux 已打包对应官方运行时，仍需在演示电脑提前试跑。
如系统提示文件来自互联网，请按学校设备管理规则允许本地运行；无管理员权限的受管电脑请提前试。

等启动窗口出现 READY，浏览器会打开 http://localhost:3000/login（端口占用会选 3001-3009）。
保持启动窗口打开。关闭窗口停止服务；数据保留在 local-data。
不要同时启动两份指向同一 local-data 的服务。

推荐三分钟演示
1. 点击“创建账号”，随意使用一个演示邮箱格式和至少 10 位密码；无需发送邮件。
   这是仅在这台电脑保存的本地账号，与线上 Supabase 账号完全独立。
2. 进入街角的 omniAI 研究工作台，输入“科技策略”。
3. 输入“降低回撤”，再输入“加入黄金”，展示多张策略卡。
4. 点击策略卡部署到模拟沙箱，展示成交记录和持仓。
5. 刷新页面，确认聊天和持仓恢复。

两种模式
默认“离线演示”：模型回答为三个明确标记的预设示例，不是实时 AI。
回测与模拟交易在本机真实计算，使用项目原有 Yahoo 历史复权收盘数据。
支持 SPY / QQQ / NVDA / GLD / TLT，数据截止 2024-12-31；没有实时行情或链上校验。
图表仅有日收盘数据，没有真实日内 OHLC/成交量；其他标的在本地包内不可用。
离线示例不解析任意个性化需求；用上述三个演示问题。

在线 DeepSeek：将 ENV-EXAMPLE.txt 复制为 .env.local，填入自己的服务端 key，重启。
在顶部切换“在线 DeepSeek”，即可使用真实模型自由提问。
账号、数据、回测仍留在本机，行情仍是上述历史快照；只有模型请求需要联网。
最多等待约 25 秒后给出明确失败提示。现场若卡住，点停止，再切到顶部“离线演示”，重发问题。
没有配置 key 时会拒绝切换在线，不会假装已连通。
API 可公开访问不代表密钥应公开。包内没有 DeepSeek key、生产数据库密钥或真实用户资料。
如果 key 已经公开发过群或仓库，建议在服务商后台换一枚演示专用 key 并保留余额。

上台前一天
在实际演示电脑上解压、启动、新注册账号、跑完上述五步。
再断开 Wi-Fi 重复三种策略和模拟执行，确认顶部是离线模式。
若打算在线展示，开 Wi-Fi 配好 key 单独验证一次；不要依赖现场首次安装或下载。
建议主讲电脑和备份电脑各保留一份已试跑的完整文件夹。

数据与分享
首次解压是空数据库。local-data 自动创建，重启保留。
给同学分发原始 zip，不要转发已经使用过的整个文件夹（里面可能有 .env.local 和本地账号）。
想从空账号重新演示，直接注册新账号；不需要删数据库。
本程序仅监听本机，不能作为公网多用户服务器。
Mac/Linux 的实际运行、真实 DeepSeek 调用与线上网站部署状态，以任务交付说明为准。
