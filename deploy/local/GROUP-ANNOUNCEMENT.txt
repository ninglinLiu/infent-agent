2. 使用额度：按账号计算，不是无限调用
目前每个账号最多每分钟 10 次对话、滚动 24 小时 100 次对话。滚动 24 小时不是每天零点统一重置，额度会随着旧请求超过 24 小时逐步恢复。
共用校园 Wi-Fi 时，额度分别按各自账号计算。一轮对话可能调用模型多次，因此这里的 100 次是对话请求额度，不是 DeepSeek 底层 API 调用次数。服务商余额、并发限制和网络状态仍会影响在线使用。发送过快先等一分钟；日额度用完则等旧请求移出 24 小时窗口。

5. 不同电脑怎么启动
Windows 10/11 x64：进入解压后的 omniai-demo 文件夹，双击 START-WINDOWS.cmd。
Mac（Apple Silicon / Intel）：在终端进入该文件夹，运行 sh START-MAC.command。
Linux（x64 / ARM64，glibc 2.28+）：运行 sh START-LINUX.sh。
等窗口出现 READY，浏览器会自动打开本地登录页；默认地址是 http://localhost:3000/login，端口被占用会改用 3001–3009，以启动窗口显示为准。演示时保持启动窗口打开，关闭窗口会停止服务。
Windows x64 已实测；Mac/Linux 已包含对应运行时，需要在实际演示电脑提前试跑。Windows ARM 需要支持 x64 模拟，32 位系统、手机和 Chromebook 不在支持范围。

6. 本地账号和数据怎么保存
首次启动是空数据库，点击“创建账号”，填写演示邮箱格式、昵称和至少 10 位密码即可，不需要收验证码邮件。本地账号与官网账号独立，不会自动同步官网记录。
聊天、策略和模拟持仓保存在该电脑的 local-data 文件夹，关闭程序后再启动仍然保留。想演示新用户流程，直接再注册一个本地账号即可。不要同时运行两份指向同一个 local-data 的程序。

7. 默认离线演示：断网也能跑完整流程
默认模式是“离线演示”，不需要网络、VPN、Supabase 或 DeepSeek 连接。按照“科技策略 → 降低回撤 → 加入黄金”依次提问，可以展示三张不同策略卡，再部署到模拟沙箱查看持仓和交易记录。
离线模式使用明确标注的三个预设示例，不是实时 AI，也不解析任意个性化要求。回测和模拟交易会在本机计算，使用历史数据，支持 SPY、QQQ、NVDA、GLD、TLT，数据截止 2024-12-31；不展示实时行情或链上校验。演示时请如实介绍这个模式。

8. 如果要在本地使用真实 DeepSeek
将包内 ENV-EXAMPLE.txt 复制为 .env.local，填入自己的有效 DeepSeek key，重启程序，再在顶部切换“在线 DeepSeek”。需要联网，并提前确认 key 和余额正常；账号与交易数据仍保存在本机，行情仍使用包内历史快照。
本地在线模式约 25 秒超时后会提示失败。现场遇到卡顿可以点“停止”，切回顶部“离线演示”，再发送上述演示问题继续。包内没有附带 DeepSeek key 或生产数据库密钥，不要把 key 提交到 GitHub 或发进群。
