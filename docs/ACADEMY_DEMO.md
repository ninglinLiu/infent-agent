# 投资研习所演示

入口为 `/dashboard` 房子上的“学习室”招牌。首次访问显示演示登录，输入昵称或直接以访客身份进入；随后依次播放三幕开场故事。主导航保留学习室、知识学习、角色模拟、设置。原绿色金融工作台已经移除；行情与 AI 研究在独立的 omniAI 入口。

## 单线内容

- 巴菲特：基于公开价值投资理念的虚构教学角色，非本人对话或背书。
- 林澈：原创量化研究专家。
- 三节短课：价格与价值、风险规则、可检验的判断。每一步只有一个确认或继续按钮。
- 四步模拟：研究候鸟咖啡、确认规则、模拟买入、复盘。公司和行情为固定剧情数据。投入 2,000 模拟币买入 20 份后，下一场景价格为 90，账户总值为 9,800，展示亏损情景。

中文角色对白、课程和剧情位于 `lib/academy.ts`，对应英文位于 `lib/academy-content.ts`。这些内容不调用模型，因此播放顺序与演示结果稳定。原有 AI 投研聊天和行情接口仍在 omniAI 工作台中。

学习室顶部和序章提供 English／中文按钮，设置页提供两种语言选项。与研究工作台共享语言偏好 `omni.lang`，刷新后保留选择；切换语言不改动课程、模拟或序章位置，也不翻译用户自己填写的昵称。

## 视觉与动画

默认启用 3D 沉浸版，参考 [David Heckhoff 的作品站](https://david-hckh.com/) 的奶油色书桌、卡通人物、蓝色全息舞台和场景转场方向。人物及书房由 `components/academy/StudyWorld.tsx` 使用 Three.js 几何体原创搭建，没有复制参考站的模型、源代码、纹理或声音。

`ImmersiveScene.tsx` 负责鼠标视差、人物挥手、加载降级和可见性控制，`app/immersive.css` 负责悬浮标签、磁吸按钮、页面入场和奶油色到深蓝的场景变化。量化导师出场时，书房下移，镜头靠近全息舞台，扫描环和粒子随时间移动。滚动仅影响轻微镜头视差，不接管用户滚动，也不自动推进剧情。

3D 代码按需加载；场景移出视口或浏览器进入后台时暂停连续渲染；不支持 WebGL 或渲染失败时回退到原创插画。设置中的“减少动态效果”及设备偏好会停止连续动画与鼠标跟随，仍保留人物静态画面。

入口和设置中均可切换到此前的轻量插画版：`MentorScene.tsx` 与 `app/academy.css`。该版本的暖白、墨绿书房和轻量 SVG 动画保留，切换风格不改变学习进度。

## 演示状态

昵称、序章位置、课程位置、模拟位置和动画偏好保存在当前浏览器的 `infent-academy-v1` 项中。这不是实际身份验证，也不保护服务端资源。存储不可用时仍可在当前页面体验，并显示无法保存提示。

刷新保留已完成步骤；重播序章保留课程和模拟记录；退出会清空演示昵称和进度。故事账户独立于原工作台的策略演示账户。

## 验证

本轮只验证桌面，不制作手机端。`npm test` 包含 21 项测试，其中新增双语步骤覆盖、原有进度兼容和昵称保留测试；`npm run eval` 为 30 条离线检索／拒答路由回归。

浏览器手动核对中英切换、课程正文、导师、剧情、设置、英文序章，以及刷新后语言与已有 30% 进度保留。`tests/browser` 补充了桌面入口与学习室双语回归用例，本轮未运行自动浏览器套件；原展示首页与 PWA 用例仍保留。

本地运行：`npm run dev`，打开 `http://localhost:3000/dashboard`。发布需另行部署当前工作区版本。
