## 动画与行情

`AsciiOrb.tsx` 是本地原创字符场动画，参考用户给出的 ASCII 动画方向，没有复制第三方脚本或引入新运行时。提供暂停按钮；隐藏、后台标签页和系统减少动画偏好都会停止字符计时器。

`QuantPreview.tsx` 调用现有 `/api/market/klines`，展示当前标的价格、K 线和成交量快照，可手动刷新。失败时价格显示空值，示意图明确标为模拟；更新失败保留的旧快照也有提示。策略流线始终标记“视觉模拟，非收益预测”。不发起模型调用，不增加付费服务。

参考资料：[用户指定的 ASCII 项目](https://github.com/kailashsr38/ascii-magic-art)、[Framer](https://www.framer.com/)。两条 X 链接无法通过公开访问读取，因此没有声称复刻其视频。
