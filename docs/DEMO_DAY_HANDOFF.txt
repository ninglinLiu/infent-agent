已实施
1. 数据库 begin_chat 限额调整为 10 次/分钟、100 次/滚动 24 小时，区分两种错误；保留事务锁、所有权校验和匿名拒绝。原有数据不清理、不迁移到本地包。
2. 工具允许最多 24 个候选输入，去重后最多执行 8 个，修复观察到的重复参数失败。
3. 模型连接在收到任何流内容前对网络错误、429 和部分 5xx 重试一次；401/402 不盲目重试。记录脱敏错误分类，输出不足不再当作完整回答。
4. 账户验证的短暂网络异常不再立即卸载已验证用户的工作台；服务端仍对每个 API 请求鉴权。
5. 聊天增加客户端等待上限；本地在线模型等待最多约 25 秒。错误后可以继续发送、切换离线。
6. 本地独立账号、PGlite 持久化数据和原 RLS 规则。数据只保存在该电脑，不能拿它当线上账号。
7. 本地行情固定使用项目原有 lessons.json：SPY/QQQ/NVDA/GLD/TLT，2019-12-31 至 2024-12-31；回测按实际窗口重算。没有伪造实时价格、链上数据或模型回答。
8. 默认离线模式是三个预设教学配置；在线模式才调用 DeepSeek。顶部、正文和数据面板均标注模式与历史数据。
9. 便携包包含五种官方 Node 22.20.0 运行时，下载包 SHA256 与 nodejs.org 校验单逐项一致。无需现场 npm install 或 Docker。
